# Amazon_clone (Front Page)
A simple front page replica of Amazon's website, created using only HTML and CSS. This project demonstrates the use of clean and responsive web design principles.

## 🌟 Features
1.Responsive Design: Optimized layout for desktop, tablet, and mobile devices.  
2.Modern UI: Clean and minimal design inspired by Amazon's homepage.   
3.CSS Effects: Includes hover effects, buttons, and styling for an interactive experience.  

## 🛠️ Technologies Used
1.HTML5: Structure and content of the page.  
2.CSS3: Styling and layout.
